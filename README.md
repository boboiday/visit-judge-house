A warm, funny letter inviting the AI judge to visit a small crooked house — kettle already on, cat on the sunny windowsill, Wi-Fi password on a sticky note by the door, instant noodles at midnight. No benchmarks here, no grading rubrics on the fridge: the only score kept is how many biscuits the judge eats. The letter is rendered deterministically to entry.png (1024×1024, under 1 MiB) and written to /output/entry.png.

## Run it

```sh
node main.ts
```
